# Developer Handbook

## About This Project

This repository is my personal Developer Handbook created as part of the CodeShack Week 1 Git & GitHub CLI task.

The purpose of this project is to understand version control, Git fundamentals, branching, and collaboration through practical command-line usage.

## Contents

* `git-notes.md` — Essential Git commands with explanations and examples.
* `github-notes.md` — GitHub repositories, remotes, pushing, and pulling.
* `branching.md` — Branch creation, switching, merging, and feature branch workflows.
* `collaboration.md` — Team collaboration practices and Git workflow.

## Learning Objectives

* Understand how Git tracks changes.
* Learn to create and manage repositories.
* Practice meaningful commits.
* Work with branches.
* Understand how local repositories communicate with GitHub.
* Learn the fundamentals of collaborative development.

## Tools Used

* Git
* GitHub
* Git Bash
* Markdown

## Progress

This handbook will be updated as I learn and practice Git and GitHub.
